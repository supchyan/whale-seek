### Что это:
Чистит все ненужные профили (не путать с учетными записями) пользователей с корпоратской винды. </br>

### Как исключить пользователя из алгоритма чистки:
 1. Открываем файл в билде по пути: `./config/black_list.json`
 2. Дописываем в него нужный `username`
 3. Запускаем программку и радуемся.
</br>

![image](https://github.com/user-attachments/assets/1ce75344-5ccc-4f75-bc22-c1e3ecdfeec1)

### Как в это контрибьютить (а зачем):
1. Клонируем репозиторий
2. Запускаем проект в `VisualStudio` (либо еще где-то)
3. Убеждаемся, что у нас стоит `.NET6.0` (либо любой другой новее)
4. Запускаем дебаггер и радуемся
